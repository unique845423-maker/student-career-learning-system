C Programming

Learn C Programming from the basics. Understand concepts, write programs and build strong programming logic.

1. Introduction to C

C is a general-purpose programming language. It is widely used for system programming, embedded systems, operating systems and learning programming fundamentals.

Why learn C?

  • Easy to understand programming fundamentals
  • Helps build strong logical thinking
  • Used in operating systems and embedded systems
  • Provides a strong base for C++ and other languages
  • Useful for understanding memory and pointers
First C Program 
#include <stdio.h>

int main() {

    printf("Hello, World!");

    return 0;
}

2. Basic Structure of a C Program

#include

Used to include required header files in the program.

main()

The main function is the starting point of a C program.

printf()

Used to display output on the screen.

3. Variables & Data Types

A variable is a named memory location used to store data. Every variable has a data type.

int

Stores whole numbers.

float

Stores decimal numbers.

char

Stores a single character.

Example 
#include <stdio.h>

int main() {

    int age = 18;
    float marks = 85.5;
    char grade = 'A';

    printf("%d\n", age);
    printf("%.2f\n", marks);
    printf("%c\n", grade);

    return 0;
}
